# ProHabeas: sistema gerenciador de casos jurídicos

Sistema web de gestão para escritórios de advocacia, desenvolvido com o objetivo de facilitar a organização e o acompanhamento das atividades jurídicas.

## Funcionalidades

- Gestão de clientes: cadastro e gerenciamento de informações dos clientes.
- Gestão de processos: organização e acompanhamento de processos judiciais.
- Controle de prazos: registro de compromissos, prazos processuais e pendências.
- Checklists: acompanhamento de documentos e etapas necessárias para cada demanda.
- Gestão de documentos: organização de metadados, identificação e acompanhamento de documentos.
- Gerenciamento de tarefas: distribuição e acompanhamento de atividades entre usuários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase (Banco de dados e API)

## Objetivo

O ProHabeas busca centralizar informações e otimizar a rotina de escritórios de advocacia, proporcionando mais organização, praticidade e controle sobre as demandas jurídicas.
